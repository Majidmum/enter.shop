
   - Нажмите кнопку отправки

4. **Проверьте логи в консоли браузера:**

## ❌ Проблемы и их решения:

### 1️⃣ Логирование показывает "BOT_TOKEN: ✗ Missing"

**Проблема:** `.env.local` файл не загружен

**Решение:**
- Проверьте, что `.env.local` существует в корневой папке проекта
- Перезагрузите приложение: `pnpm dev`
- Убедитесь, что токены правильно скопированы

### 2️⃣ Логирование показывает "Telegram API error"

**Проблема:** Неверный токен или Chat ID

**Решение:**
- Проверьте токен в `.env.local` (должен начинаться с цифр и содержать `:`)
- Проверьте Chat ID (должен быть число, часто с минусом)
- Убедитесь, что бот был добавлен в чат
- Переправьте сообщение боту: `/start`

### 3️⃣ Консоль пуста, никакого логирования

**Проблема:** Код не вызывается или браузер использует кэш

**Решение:**
- Очистите кэш браузера (Ctrl+Shift+Delete)
- Перезагрузите страницу (Ctrl+F5)
- Убедитесь, что вы нажали кнопку отправки/оформления

### 4️⃣ CORS ошибка

**Проблема:** Браузер блокирует запрос к Telegram API

**Решение:**
- Это нормально - браузер может блокировать cross-origin запросы
- Но Telegram API должен работать в любом случае
- Проверьте логирование Telegram ответа (может быть успешным несмотря на CORS ошибку)

## 📱 Проверка бота в Telegram:

1. **Откройте Telegram и найдите вашего бота**
2. **Отправьте команду:** `/start`
3. **Проверьте, получен ли бот в чате**

Если бот не получил сообщение:
- Проверьте Chat ID
- Убедитесь, что бот добавлен в нужный чат/канал

## 🆘 Если все еще не работает:

1. **Проверьте в Telegram Desktop:**
   - Откройте Desktop версию Telegram
   - Проверьте, что сообщения приходят туда

2. **Создайте нового бота:**
   - Откройте @BotFather
   - Команда: `/newbot`
   - Скопируйте новый токен в `.env.local`
   - Перезагрузите приложение

3. **Проверьте логи еще раз:**
   - Смотрите полный ответ от Telegram API
   - Это поможет понять, в чем проблема

## 📝 Пример правильного `.env.local`:

```env
# Telegram Bot Configuration
VITE_TELEGRAM_BOT_TOKEN=123456789:ABCDefGHIjklmnOPqrstuvWxyzABCDefGHI
VITE_TELEGRAM_CHAT_ID=987654321
```

**Важно:**
- Не должно быть пробелов вокруг `=`
- Токен должен содержать `:` (двоеточие)
- Chat ID обычно положительное или отрицательное число

## 🎯 Краткая инструкция по отладке:

1. Перезагрузите: `pnpm dev`

3. Отправьте заявку/заказ
4. Смотрите логи в консоли
5. Если видите ✅ "Message sent successfully" - все работает!
6. Проверьте Telegram чат
